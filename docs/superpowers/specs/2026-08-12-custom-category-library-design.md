# 自定义分类库设计

## 目标

用户创建一次自定义分类后，后续可直接复用；在设置页可重命名或删除分类。

## 交互

- Skill 详情的分类下拉分为“来源分类”和“自定义分类”；当前分类只出现一次。
- 选择“新建分类…”后输入名称并保存。名称会写入持久化分类库，随后立即可用于任何 Skill。
- 设置页显示“自定义分类”，每项展示引用数量，提供重命名和删除。
- 重命名会原子地更新全部引用该分类的 Skill。
- 删除被引用分类时显示确认层；确认后，引用它的 Skill 移至未分类。未被引用时可直接删除。
- 内置来源分类不可在设置中重命名或删除。

## 数据与兼容性

- `Settings` 新增带 serde 默认值的 `customCategories: string[]`，保留现有 `skillCategories` 映射。
- 创建或手动指定非内置分类时自动加入该数组；数组去重、去首尾空白、按名称排序。
- 旧配置缺少该字段时以空数组载入，不显示配置损坏提示。

## 验证

- Rust 覆盖创建、重命名、删除分类及被引用分类回退未分类。
- 前端覆盖创建后在其他 Skill 下拉复用、设置页重命名与删除确认。
